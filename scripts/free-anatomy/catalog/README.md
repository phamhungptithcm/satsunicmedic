# AC-01 source catalog

BodyParts3D, © The Database Center for Life Science licensed under CC Attribution 4.0 International.

Sources retrieved/checked 2026-10-02:
- [Official downloads](https://dbarchive.biosciencedbc.jp/en/bodyparts3d/download.html).
- [Official license](https://dbarchive.biosciencedbc.jp/en/bodyparts3d/lic.html), updated 2025-02-27, CC BY 4.0. Preserve legacy OBJ header notices too.
- `isa_element_parts.txt`: official IS-A concept → source geometry mapping.
- `isa_inclusion_relation_list.txt`: official IS-A classification hierarchy. Validated but never presented as part-of anatomy.
- `partof_inclusion_relation_list.txt`: official PART-OF hierarchy used for the source-parts drilldown.

`coverage.json` and `discovery.json` are generated by `node scripts/free-anatomy/coverage-audit.mjs`; do not edit them. The former retains exact mapping and byte/hash receipts. The latter is the compact browser projection. Regenerate after catalog changes; tests reject a stale catalog hash or source receipt. Both must be included in source snapshots.

The reference contains 2,905 source concepts and 2,234 unique source geometry IDs. It is independent of the previous 1,258-object imported catalog, but NOT an independent complete anatomical standard. Coverage is source-ID coverage only. Every record keeps clinical review and content review separate from geometric presence. Whole-human completeness remains unknown, even when source-ID gaps are zero.

No new resource is fetched at runtime. Names are rendered as text. English names remain source names until translations are verified. PART-OF relationships may be incomplete; no missing relation is inferred from bounding boxes or set inclusion.
